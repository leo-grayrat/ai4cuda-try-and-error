# 研究起点与当前范围

用户原始思考针对 FlashRT：论文介绍图方法，仓库却仍有长篇 AGENTS.md。代理遇到问题便追加“不要”“必须”，由此产生对规则累积、遗漏以及整理压缩的疑问。来源是用户提供的《Retire the Abstractions 等四篇文章》和《haozhi reply》；后续曾误记为 KernelRL，又错误地以 CUDAAgent 代替正式研究对象。恢复后的材料固定在 [FlashRT 来源与实测](flashrt/README.md)。

| 问题 | 所需证据 |
| --- | --- |
| 增加要求能否改善表现 | 同一真实任务下，对有明确来源的要求组合比较正确性、持续输出和性能 |
| 收益是否值得成本 | 实际读取、生成、工具运行与失败成本，结合交付质量判断 |
| 长篇要求是否容易遗漏 | 对共同要求逐项核对，尤其关注需要理解、解释和判断的内容 |
| 权限或检查是否更有效 | 保留 FlashRT 原有检查，再对额外机制做明确且可执行的比较 |

原文整理应保留目录作用范围、强制程度、适用条件及示例。条目数量变化同时改变内容时，结论限于实际比较的要求组合。逐字切分只是来源索引；有了任务和读取策略后，才能评估按需组织的收益。

任务须契合 FlashRT 的顺序参考、适配器约定、图执行和流式状态。现成应用需要的资源尚待落实。新增轻量应用须明确标识，并验证上述流程，不可沿用旧 CUDA 算子任务充当完整复现。

论文继续遵循用户指定的 Nature 工作流：先证据和论证，再结果、图表与正文；当前不写尚无结果支撑的结论。工作语言为中文，未预设目标期刊。
