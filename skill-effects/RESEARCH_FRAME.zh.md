# 研究起点与当前范围

研究动机是 AI 遇到问题就追加“不要”“必须”，让说明越来越臃肿、难以遵守，继而产生整理和压缩的想法。用户于 2026-10-19 进一步明确：本项目以原始 CUDA Agent skill 及其格式化、优化等处理版本为比较对象。构造一遍膨胀过程不是主任务。

正式实验使用固定版本的原始 CUDA Agent skill，比较原文、仅格式化、去重优化，以及从原文抽出的不同规则子集。相同文档下再切换写入权限和提交检查器，测量表现、成本与遗漏。先前构造的追加历史和重复压力材料保留为探索记录，退出正式主实验。

## 四个问题如何落实

| 问题 | 直接比较与证据 |
| --- | --- |
| 加规则是否改善表现 | 从同一原文抽出的 core、workflow、完整要求；保留共同示例，比较正确性、性能与要求落实 |
| 收益是否值得成本 | 原文、格式化和优化版的实际输入、缓存、生成、工具耗时与交付质量 |
| 要求多时是否遗漏非量化部分 | 对共同要求单独复核，隐藏条件审阅预期解释、结果说明及连贯文风 |
| 权限和检查器是否更有效 | 原文与优化版各自在相同预算下进行无机制、仅权限、权限加检查器对照 |

规则子集改变了要求内容和数量，结论限于这一批原文条目；不把它解释为与内容无关的纯数量规律。原文有 45 个映射条目，其中包括强制要求、条件建议和示例做法，不能统称为 45 条同强度命令。

## Nature 工作流

使用已安装的 nature-writing：以问题、来源和证据安排为先，实验后先写结果，再组织引言与讨论，摘要最后完成。配图和成稿审阅在对应阶段使用 nature-figure 与 nature-reviewer。工作语言为中文，未预设目标期刊。
