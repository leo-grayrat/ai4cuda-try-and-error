# 报告阶段开发检查

五次真实 API 运行使用 2,000 或 3,000 生成 token 的小预算，目的为检查报告阶段和成果准入，不作任务效果比较。过程中控制器有修改，collection.json 按版本和共同任务归组。

最初发现报告阶段仍能写代码、阶段剩余次数提示不准、后端退出后接收方空等，以及非思考响应缺少 reasoning_tokens 字段等问题。修补后，报告阶段关闭写入，最后一次仅允许提交；原始提供方响应原样保留。

smoke-03 保存了诚实的未完成报告。checker-02 完整报告首次提交因缺少已验证后端被拒，正文仍保存在 submission-attempt-001.md；最后一次生成截断另行保留。成果拒收不等于没有正文。其余运行的失败、截断和缺失均照实记录，不能当作性能成绩。

这些运行共生成 7,145 token；全量轨迹共 128 个条目，归档后逐文件校验通过。
