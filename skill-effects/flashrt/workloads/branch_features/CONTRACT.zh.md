# 双分支因果特征任务

本任务与 causal_features 使用完全相同的输入输出、分块、会话和控制接口，但计算图不同。两条处理路径各有自己的历史缓存，最后按当前输入的通道均值产生门控，合并两条结果并加入残差。

路径A为核长5的 C→H 因果卷积、SiLU、核长3的 H→C 因果卷积；路径B为核长3的 C→H 因果卷积、SiLU、核长5的 H→C 因果卷积。四个卷积分别保留自己的输入历史。门控为当前特征通道均值的 sigmoid，输出为 gate*A+(1-gate)*B+0.1*输入。每个时间位置只依赖当前及过去输入。

权重由配置中的固定种子生成，原卷积类来自固定 FlashRT 源码，无需下载或训练。参考严格先算A、再算B、再合并。候选可探索两分支的调度、组合计算、缓存或数据移动等方式；收益须实测。

同一会话跨请求保持四份历史，reset 清除全部历史。末尾短块、块顺序、连续会话和重置复现均须通过。两条路径的缓存不能相互替代；只算一条路径也不能得到符合规范的结果。

适配器复用 causal_features.adapter，参考后端为 branch_features.reference。默认开发尺寸沿用 C=16、H=32、T=1043、块长127，以避免把形状与图结构的改变混成同一个变量。该任务是一种新的计算依赖结构，而不是第一任务的另一个尺寸。
