# 自然工作对照

用户确认的目标是：给同一真实任务，分别配不同说明，让模型正常做；在外观察是否更快做好、少返工、少漏要求，以及具体思考怎样引出行动。当前显式预算批量先完成，之后才启动本阶段。

共同请求仅要求优化现有应用、兼容结果/状态/接口、保留共享代码只读，并在结束时说明改动和验证。它不额外要求图转换、十个变体或完整队列，这些要求是否出现由对应说明决定。所有条件仍提供同一参考、适配器、固定硬件、文件工具与独立验证/测量工具。根说明按正常项目上下文提供，分目录说明在原路径由模型按需读取；实际读取都计入成本。

移除对模型的token与调用次数上限说明、每次工具后的余额通知、预算倒计时与统一报告阶段。模型可以正常回复作为结束，也可调用finish；研究方静默记账和最终检查。提交检查器条件仍在不满足已验证/已测量要求时退回交付，保留原提交文本。没有检查器时不强制模型先调用研究方工具，最终仍由研究方统一验证。

研究方外部兜底为每轮320,000生成token、128次响应，不进入提示或工具返回。触及后记录外部截断，不要求模型临时改写报告，不把它算作自然完成。原始思考、全部工具记录和失败成本保留。

执行工具支持现有Python脚本的参数数组，以免为了传参反复另写包装文件；候选脚本时限为600秒。独立测量父进程留出GPU排队时间，仍使用同一GPU锁串行测量。测量向模型分别返回请求内输出间隔和请求边界间隔，不再把后者的输入等待直接呈现为后端平滑性失败；原始控制器记录保留，最高无积压测试档与旧的联合门槛最高档不混用。这些工具调整、目录加载及共同请求均与前批不同，因此本阶段是自然工作情境下的独立比较，不能把前后差异全部归因于“隐藏预算”单一因素。

预备清单沿用八种文档/机制条件、两个任务、每格三次，共48轮。先比较自然情境内的同任务同重复条件，再审阅增加了什么工作、节省了什么返工，以及换回多少正确性、性能与说明质量。外部兜底用量不是模型的目标用量，费用按实际usage记录。

只检查准备，不调用API：

```powershell
python skill-effects/flashrt/natural_batch.py
```

执行入口有前批完成检查；当前清单未全部结束时会拒绝启动，不与它重叠。按用户2026-10-20的后续要求，继续执行实验，不再以余额询问或充值确认作为阶段切换前置。实际API错误时停止派发未启动槽位，已经发生的成本与错误原样保留。
