**Every** test or benchmark script you write must guarantee that all
backend subprocesses it spawned are dead before the script exits. This
is non-negotiable. Leaked processes corrupt subsequent runs, waste GPU
memory, and — most importantly — mean the harness did not actually
complete, which invalidates any results you recorded.

Pattern:

```python
import os, signal, subprocess

proc = subprocess.Popen(
    [...],
    preexec_fn=os.setsid,  # new process group so we can kill children
)
try:
    # ... drive the backend through the adapter ...
finally:
    # 1. Ask nicely
    proc.terminate()
    try:
        proc.wait(timeout=15)
    except subprocess.TimeoutExpired:
        # 2. Kill the whole process group
        os.killpg(os.getpgid(proc.pid), signal.SIGKILL)
        proc.wait()
    # 3. Clean up IPC handles
    # (remove /dev/shm/<prefix>* files)
```

After every harness run (success or failure), execute a quick orphan
check:

```bash
pgrep -f 'flashrt/apps/<app>/backend' || echo "no orphans"
```

If orphans exist, kill them before proceeding. If a harness
consistently leaks processes, fix the harness before recording any
results from it.
