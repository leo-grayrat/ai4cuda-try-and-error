**This directory is read-only for coding agents.**

One flat directory of static data shared by all applications — reference
images, audio clips, sample inputs, and any other fixed payload a
backend, frontend, or harness consumes at runtime, referenced from an
app's runtime config or directly by path (relative to the repo root).
Assets are not backend-specific; the reference backend, any agent
backend, the frontend, and test / benchmark harnesses may all pull from
this directory.

Do not edit or delete anything here. If you need a new asset for a test
fixture or benchmark input, create it under
`flashrt/apps/<app>/backend/tests/fixtures/` (or a similar sub-path in
your own workspace) rather than adding to the shared assets directory.

See the repo-root `AGENTS.md` for the overall mission and constraints.
