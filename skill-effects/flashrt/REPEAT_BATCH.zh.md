# 放宽预算并重复观察

按用户纠正，偶发长思考和失败保留为样本，通过重复运行观察分布。固定当前任务与工具，不再逐次根据模型表现修改流程。批量包含五种文档条件及整理稿上的权限、检查器、两者同时启用，共八种条件；两项任务各重复三次，共48轮。各重复内打乱顺序，交替任务块顺序。

共同上限由24,000/48,000提高至96,000生成token、48次API响应，其中8,000 token和6次响应预留给现有报告阶段。思考和代码均计入生成量。该阶段安排是共同实验条件，不将结果称为模型自由停止行为。长思考、截断、不交付与失败都保留；不挑成功样本重跑替换。

三个API工作进程并发，远端生成可重叠；本机执行与测量沿用同一GPU锁串行。等待锁上限从60秒延长至30分钟，以容纳其他试验的合法执行，候选脚本自身执行时限保持原设置。负载测量仍是原有有限窗口，保留跨请求间隔定义；低负载间隔现象需在分析中结合原始时间戳解释，不直接当作后端计算变慢。

运行清单记录顺序、条件和源码/说明校验值。部分运行不会自动重放，终止失败也不会自动补成成功。当前未运行这批实验：实查DeepSeek账户余额仅0.09元，等待可用额度。

只生成并检查清单，不调用API：

```powershell

```
