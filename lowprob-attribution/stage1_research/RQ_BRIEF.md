## 1. 命题（一句话）

CUDA Agent 将 PPO 训练不稳定归因于「CUDA 在预训练语料中 <0.01% → 基础模型对 CUDA token 赋近下限概率 $\pi_\theta \approx 10^{-9}$ → 精度差异放大为重要性比率爆炸」。本文检验该因果链的**第一环**：CUDA/Triton 词汇在生成时是否确实构成低概率尾部。

## 2. 命题的精确层次

因果链有四环，本文只碰第一环：

| 环节 | 内容 | 本文状态 |
|---|---|---|
| (i) 语料占比 | CUDA < 0.01% 预训练数据 | **不检验**（不可检验，需语料统计） |
| (ii) 生成时概率 | 该占比导致 CUDA token 条件概率近下限 | **本文检验** |
| (iii) 精度放大 | 近下限概率使 BF16/FP16 差异放大为比率方差 | 不检验（需训练） |
| (iv) 训练崩溃 | 比率爆炸导致 17 步崩溃 | 不检验（需训练） |

**(ii) 是 (iii)(iv) 的前提。若 (ii) 不成立，(iii)(iv) 的归因失去依据。**

## 3. 判读树（采集前冻结）

- **判读 1**：CUDA token 低概率率**不显著高于**其他，**且** `after_failure` 显著高于 `initial` → 因果链起点不成立，替代解释（分布外上下文）成立。
- **判读 2**：CUDA token 低概率率**显著高于**其他，**且各上下文下方向一致** → 起点成立。
- **判读 3**：两者混合 → 需更细分解。

## 5. 可证伪性

**若在未微调的基础模型上测出 CUDA token 概率接近下限**，则本文结论（"在已对齐模型上不成立"）与原文可同时成立，因果链在基础模型阶段完整。**本文未做该对照**（需基础模型权重），并在论文 §5.2 与附录 A 明确标注为最高优先级后续。
