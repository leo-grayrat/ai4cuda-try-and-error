# 第二轮隔离采集试跑（2026-09-27）

## 采集门槛

OpenCode 1.18.12、`deepseek/deepseek-flash`、相同 Python/CUDA 环境及任务版本下，`vector_affine` 和 `row_reduce` 各自完成无额外 skill、完整 skill、精简 skill 三种条件的单次试跑。每条运行保存了逐步模型用量、缓存用量、工具与反馈、源码版本、终止原因和独立评测；六条候选均在每个评测形状上启动 Triton kernel 并通过数值检查。**两任务三条件的采集可行性门槛已通过；这六条仍是开发试跑，不用于 skill 效果估计。**

最初把实时任务目录放在 `runs/<trial>/work`，使 agent 可以沿父目录读到其他试跑。旧 `row_reduce` 完整提示轨迹实际读取了前一条试跑的评测和源码，故不作条件比较。现将 agent 实时工作目录放在系统临时目录的随机独立子目录，运行结束后才复制候选回 `runs/<trial>/work`；这降低了意外跨试验读取风险，但不是操作系统级文件沙箱。第一条隔离无提示运行把 PyTorch 参考实现原样复制到候选，旧数值评测误判为完成；现评测逐形状确认实际 Triton JIT 启动，并将这条复制参考的运行判为无效实现。所有这些失败轨迹均保留在本机。
